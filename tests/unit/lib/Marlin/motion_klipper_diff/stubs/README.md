Stand-ins for the firmware headers that `precise_stepping`, `input_shaper` and `pressure_advance` include. CMake copies the real motion sources and these stubs into one tree in the build directory. Thus the relative includes of the real sources (for example `"../../inc/MarlinConfig.h"`) find these stubs. The values are those of the CORE One L (CoreXY, `ADVANCED_STEP_GENERATORS`, 1 MHz step timer).
